# CoMo Recipes

Our household's recipe collection, in two repos:

- [comorecipes-database](https://github.com/CodyCBakerPhD/comorecipes-database) holds the recipes and ingredients themselves, one YAML file each, validated against their schemas. Add or fix a recipe there.
- [comorecipes-app](https://github.com/CodyCBakerPhD/comorecipes-app) holds the web app that renders them, published at https://codycbakerphd.github.io/comorecipes-app/.

Both started out here, and this repo keeps that shared history. The site used to be published from here too, so `redirect/` is the page that now sends visitors of the old address, recipe pages included, on to the new one.
